# PDF Master Pro – Ultimate Edition 👑

تطبيق مكتبي متكامل واحترافي لمعالجة وتحرير مستندات PDF والصور، مبني وفق أحدث المعايير الهندسية والواجهات الرسومية الحديثة (مستوحى ومطابق للهوية البصرية المعتمدة بالألوان: Navy `#172536`, Deep Blue `#24374D`, Teal `#278B91`, Gold `#E5A63B`, Background `#F3F5F8`).

---

## 🌟 الميزات والقدرات الرئيسية

### 1. عارض ومحرر PDF متطور
- **عارض صفحات فائق الدقة**: مبني على تقنية `QtPdf` المدمجة السريعة، مع دعم تكبير/تصغير سلس (`Ctrl` + عجلة الفأرة، أزرار، وقائمة نسب من 50% إلى 200%).
- **شريط مصغرات مرئي (Thumbnails Bar)**: استعراض جميع صفحات المستند مع ترقيم دائري واضح وتحديد الصفحة النشطة.
- **تبويبات المستندات (Tabs)**: إمكانية فتح مستندات متعددة والتنقل بينها بسهولة.
- **لوحة البداية الترحيبية (Home Dashboard)**: بطاقات وصول سريع لكافة الأدوات مع منطقة سحب وإفلات تفاعلية وسجل للملفات الأخيرة.

### 2. ضغط ملفات PDF بثلاثة مستويات ذكية
- **خفيف (جودة عالية)**: مناسب للمستندات والطباعة الرسمية، مع إعادة ضغط التدفقات وتحسين الكائنات.
- **متوسط (توازن مثالي)**: تقليل دقة الصور إلى 150 DPI وإعادة ضغط JPEG بجودة 75% مع إزالة الموارد المكررة.
- **قوي (أقل حجم)**: تقليص فائق إلى 96 DPI مع ضغط أقصى للكائنات وتوليد جداول تدفقات محسنة.
- **حساب حقيقي ودقيق للتوفير**: يعرض الحجم الأصلي، الحجم المتوقع والفعلي، ونسبة التوفير المئوية دون وعود وهمية.

### 3. دمج وتقسيم وإدارة الصفحات
- **دمج مستندات متعددة**: ترتيب الملفات بالسحب والإفلات وحفظ الملف المدمج.
- **تقسيم مرن**: تقسيم كل صفحة في ملف مستقل، أو حسب عدد ثابت من الصفحات، أو استخراج نطاق مخصص.
- **إدارة الصفحات**: تدوير الصفحات (90°، 180°، 270°)، تكرار، حذف، واستخراج صفحات معينة.

### 4. العلامات المائية والتأمين
- **إضافة علامات مائية نصية وصورية**: تخصيص زاوية الدوران، الشفافية، الحجم، واللون.
- **إزالة العلامات المائية والتغطية (Redaction)**: محو العلامات المائية مع مراعاة الحفاظ على بنية المستند.
- **حماية وتشفير عسكري AES-256**: حماية بكلمة مرور للمستخدم وكلمة مرور للمالك، مع ضبط أذونات الطباعة والنسخ والتعديل بدقة.

### 5. محرك معالجة الصور الشامل (Pillow)
- ضغط ومعالجة الصور دفعة واحدة (Batch Processing).
- تغيير الأبعاد والدقة وتدوير وقلب الصور.
- التحويل الفوري بين صيغ PNG وJPEG وWebP بجودة مخصصة.
- استخراج جميع الصور المضمنة في PDF أو حذف صور محددة من الصفحات.

### 6. التحويل والتعرف الضوئي (OCR)
- **تحويل الصور إلى PDF**: تجميع مجموعة صور في ملف PDF واحد عالي الدقة.
- **تحويل PDF إلى صور**: تصدير صفحات PDF كصور PNG أو JPEG أو WebP بدقة 150/300 DPI.
- **التعرف الضوئي OCR**: دعم اللغتين العربية والإنجليزية بواسطة محرك Tesseract OCR.

## 🚀 طريقة التثبيت والتشغيل

### متطلبات التشغيل:
- نظام تشغيل: Windows 10 أو Windows 11 (64-bit).
- بيئة Python 3.10 أو 3.11 أو 3.12.

### 1. تثبيت الاعتماديات:
```bash
pip install -r requirements.txt
```

### 2. تشغيل التطبيق مباشرة:
انقر نقراً مزدوجاً على ملف:
```bash
run_app.bat
```
أو عبر سطر الأوامر:
```bash
py -3.12 main.py
```

### 3. التثبيت والتشغيل عبر مثبت Windows الرسمي (Inno Setup Installer):
يحتوي مجلد `installer_output` على ملف التثبيت المكتبي النهائي:
```bash
installer_output\PDFMasterPro_Ultimate_Setup_v3.5.0.exe
```
يقوم المثبت بنقل البرنامج إلى مجلد البرامج، وإنشاء اختصار سطح المكتب، وقائمة ابدأ، وربط امتداد `.pdf` بالبرنامج تلقائياً.

### 4. إعادة بناء ملف التثبيت (Inno Setup):
إذا رغبت في إعادة تجميع المثبت بنفسك، استخدم سكريبت Inno Setup:
```bash
"C:\Program Files\Inno Setup 7\ISCC.exe" PDFMasterPro_Setup.iss
```
